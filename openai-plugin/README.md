# Globestudio plugin for ChatGPT and Codex

Make, edit and embed dotted world maps and animated 3D globes with [Globestudio](https://globestudio.app).

## What is inside

- `skills/globestudio`: the globestudio skill. It teaches the link format, the 21 looks, the settings and how to embed a globe in a site or app.
- `mcp.json`: the hosted Globestudio MCP server at https://globestudio.app/mcp. No account or key. Its six tools are read-only: `list_presets`, `find_presets`, `build_share_url`, `read_share_url`, `embed_snippet` and `preview_url`.
- `assets`: the listing icons.
