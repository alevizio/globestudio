# Research

Topic-scoped deep dives. Each report should have:

1. **Date and confidence rating** at the top.
2. **Executive summary** — 3–5 sentences anyone can read.
3. **Key findings** — each with cited sources and a ✅/⚠️/❓ trust marker.
4. **Comparison table** when applicable.
5. **Risks & uncertainties** — what we couldn't confirm.
6. **Recommendations** — actionable, ordered by priority.
7. **Sources** — every URL referenced, with a note on trust.

The format above is the
[deep-researcher](https://github.com/alevizio/better-claudio) skill
output. Stick to it so reports stay comparable.

## Naming

`YYYY-MM-topic-slug.md` — chronological by default, sortable in the
file tree.
